## Prompt

```text
You are a software tester. Write 6 test ideas for the password rules delimited by three hashes. Use our team's test idea format.
###
A password must be 8 to 20 characters long and contain at least one digit and one uppercase letter.
###
```

## Response

Here are 6 test ideas covering boundary conditions, character composition, and edge cases based on your specified password rules:

* **Verify minimum length boundary (8 characters):** Enter a valid 8-character password containing at least one digit and one uppercase letter (e.g., `Password1`) to confirm it is accepted.
* **Verify just below minimum length boundary (7 characters):** Enter a 7-character password containing a digit and uppercase letter (e.g., `Passwo1`) to confirm it is rejected with the appropriate error message.
* **Verify maximum length boundary (20 characters):** Enter a valid 20-character password containing at least one digit and one uppercase letter (e.g., `Pass1` followed by 15 lowercase letters) to confirm it is accepted.
* **Verify just above maximum length boundary (21 characters):** Enter a 21-character password containing a digit and uppercase letter to confirm it is rejected for exceeding maximum length.
* **Verify missing digit condition:** Enter an 8-to-20 character password with uppercase and lowercase letters but no numbers (e.g., `Password`) to confirm it is rejected for missing a digit.
* **Verify missing uppercase letter condition:** Enter an 8-to-20 character password with digits and lowercase letters but no uppercase letters (e.g., `password1`) to confirm it is rejected for missing an uppercase letter.
